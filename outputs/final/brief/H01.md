# Short brief: A new formulation after an existing NIR pilot

*Short view built by code from the saved run JSON (no model call). Full answer: [H01.md](../H01.md).*

**Decision status:** Provisional assessment (the customer's premise is not supported by the sources)

Do not reuse the old NIR calibration: calibrations are matrix-specific, and a new API and excipient blend is a new matrix. Rebuild and validate the NIR reflection calibration on representative samples of the new blend with an independent reference assay. Test Raman as a separate method with its own calibration; adding Raman does not keep the old calibration valid. A fused NIR+Raman model is only a later hypothesis, tested if a single method misses your accuracy target.

## Measurement concept

NIR diffuse reflection fiber probe at the existing feed frame position; optional Raman fiber probe (785 nm excitation class, per the published feed-frame example) at the same sampling spot if Raman or NIR + Raman proceed. **Location:** Tablet press feed frame, in-line, probes inserted into the powder flow. **Fiber link:** Vis-NIR silica fibers for NIR; the Raman link uses silica fibers with metal-coated jackets to avoid polymer fluorescence background. [S01 p.15; S02 p.7]

## Spectral range

- **NIR:** Nominal NIR range 780-2500 nm; the usable range depends on the installed spectrometer, fiber and probe. [S01 p.10]
- **Raman:** Raman is reported as Raman shift in cm-1 with the laser excitation wavelength stated separately; the usable range depends on the instrument, fiber and probe actually selected. [S01 p.11]

## Risks and uncertainty

- The new blend may differ so much spectrally that even a rebuilt NIR model needs many more reference samples than planned.
- NIR reflection signals are sensitive to surface characteristics and particle size, so physical differences between blends can mimic composition changes. (related AFS source: S01 p.17, "the method is sensitive to the surface characteristics and fat globule size."; not checked against this sentence)
- Fluorescence from the new API or excipients may swamp the Raman signal, removing the comparison and fusion options. (related AFS source: S01 p.11, "superposition of luminescence (fluorescence), which has a significantly higher intensity."; not checked against this sentence)

## Feasibility plan

- **Next step:** Run the multi-method lab trial on representative samples of the new blend with an independent reference assay, rebuilding the NIR calibration first.
- **Reference measurements:** Independent laboratory assay of API concentration for every calibration and validation sample.
- **Decision basis:** Go/no-go criteria (acceptable prediction error, sensitivity to blend change) are set by the customer; the published fused NIR+Raman example is a precedent, not proof for this blend.
