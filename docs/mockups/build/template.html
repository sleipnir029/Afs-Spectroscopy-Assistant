Answer page: three type, layout and blueprint directions

Mockups for tasks 5.10 (layout and hierarchy) and 5.11 (academic fonts, setup diagram drawn as a blueprint). They are static and nothing in the app has changed. Every direction shows the same slice of the answer page, in order: question, recommendation, setup drawing, options, and one expanded detail section.

Content source: all text, IDs and citations are copied from the saved dev output outputs/dev/D03.json (option O2, recommended). The drawing was written by hand for this mockup. In the app it would still be drawn by code from the option.

The drawing's callouts link to the sections. Each callout on the drawing (P1–P3, M1–M2, Q3) carries the same ID as the parameter, method or open question it points to below. A shows the hover state, where P2 lights up on the drawing and in the table together.

Sources (fetched 2026-10-18):
  1. Adobe Fonts, Source Serif repository (OFL-1.1; Source Serif 4 adds optical sizes; WOFF2 provided): github.com/adobe-fonts/source-serif
  2. Source Sans LaTeX package documentation (Source Sans 3, OFL 1.1; lining and tabular figures): CTAN sourcesans
  3. Production Type, Newsreader (commissioned by Google Fonts for long-form screen reading; 3 optical sizes, 7 weights): productiontype.com
  4. STIX Two (OFL, built by a group of scientific publishers for technical publishing; considered and not used): CTAN stix2-otf README, Fontsource
  5. IBM Plex (OFL-1.1, Sans/Serif/Mono superfamily; already self-hosted in the app): github.com/IBM/plex
  6. ISO 128-2:2022, basic line conventions for technical drawings (line types and widths): ISO 128-2 catalogue entry
  7. Blueprint and cyanotype history (white lines on Prussian blue; diazo "whiteprints" with blue lines on white replaced them from the 1940s): Wikipedia: Blueprint, Wikipedia: Cyanotype
  8. Pairing guidance (serif with sans for contrast within harmony; keep the role assignment consistent): Typewolf
