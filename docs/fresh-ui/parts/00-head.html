Four chat-first takes on a cited first assessment

Concept mockups for the AFS Spectroscopy Assistant. Every sentence, citation, cost class and timing comes from a real development run (a whey-stream protein enquiry). Each concept shows the same flow: paste the enquiry, watch it run, read the answer with rich blocks, ask a follow-up, add customer facts and see what changed, then verify a citation. Turns after new facts are marked illustrative, because no real re-run exists yet, and they only reuse claims from the real run.

1 · Brief

Recommended

Take: a classic single-column chat, typeset like a memo. Rich blocks inline (recommendation, options, sketch, what changed); a pinned strip shows the current recommendation.

Signature: an evidence margin running beside the thread. Each claim’s verbatim AFS quote sits next to it, and clicking opens the quote in its page text with the code check.
