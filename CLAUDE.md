# CLAUDE.md — AFS Spectroscopy Assistant (Team Helios)

Hackathon project: an assistant that turns an in-line spectroscopy customer enquiry into a cited first technical assessment for Art Fiber Systems (AFS). Deadline: **Sun 18 Oct 2026, 23:59 Berlin**.

## Read first
- `PHASES.md`: phase plans and the per-phase process. **Never implement a phase whose plan is not approved.**
- `STATUS.md`: current phase, done, next, blockers, check results. Update it after every step.
- `DEVIATIONS.md`: every change from the approved plan, logged *before* acting, with the reason.
- Master plan v3: `~/.claude/plans/in-this-repository-you-ll-cozy-knuth.md`.

## Working rules
- **Plan → approve → implement → check → review → close.** Plans are fixed during planning, not during implementation. If a plan turns out wrong, stop, log it in DEVIATIONS.md, and ask.
- Don't assume. Ask the user when a decision is theirs. Surface uncertainty.
- No self-approval. Each phase gets an independent reviewer pass, then the user gate.
- **uv only:** `uv add`, `uv sync`, `uv run …` (python, pytest, ruff, CLI). Commit `uv.lock`. No bare pip or python.

## Challenge rules we must not break
- The supplied AFS materials are the main source. Important claims cite them as `S01 p.10` (1-based PDF page; S02 = slide number; `S01 Table 1 (p.6)`).
- An external citation must include the quoted passage and URL. Whether we use external references at all is decided after the Q&A.
- H01–H06 answers must be generated by the assistant: **no manual editing, no case-specific hard-coding.** H01–H06 are a held-out test set. Develop on D01–D08 and our own adversarial enquiries. Any change after looking at H outputs must be generic and logged in DEVIATIONS.md.
- Never invent spectra, results, accuracy, detection limits, response times, fiber lengths, product codes, prices, or client facts.
- No scenario IDs (`D0x`, `H0x`) or scenario-specific content in `knowledge/`, `skills/`, `src/`, or prompts (enforced by a lint test).

## Git rules (from the user's global rules)
- Never remove a tracked file or commit a deletion unless the user explicitly asks for that file.
- Stage named paths only. Never `git add -A` or `git commit -a`.
- Before every commit, run `git status` and `git diff --cached --name-status`. Unstage any unrequested `D`.
- Don't add `.gitignore` entries without asking. `resources/` (organizer files, copyrighted) is ignored and must never be committed.
- Commit work as it is made. Derived knowledge and our own notes are committed.

## Layout
- `resources/`: organizer files (local only).
- `knowledge/`: derived page text, S02 notes, scopes, tables, rules, graph (committed).
- `src/afs_assistant/`: package.
- `skills/`: progressive guidance.
- `scenarios/`, `outputs/`, `runs/`: data and results.
- `.pi/`: chat shell (Phase 4).
